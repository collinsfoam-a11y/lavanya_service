# Pilot Issue Register

> Each issue gets one row. Update status as issues are resolved, deferred, or escalated.

## Categories

- **BUG** — Software error or unexpected behavior
- **UX** — Confusing UI, unclear label, workflow friction
- **DATA** — Missing brand/service center/technician/product master data
- **WORKFLOW** — Business process doesn't match system workflow
- **PERM** — Role permission wrong or missing
- **REPORT** — Report data incorrect or missing
- **TRAIN** — Staff training gap
- **SAFETY** — Suspected safety-lock bypass, live send concern, auto-close concern

## Severity

- **P0** — Blocks daily operations, safety risk
- **P1** — Prevents one workflow, workaround exists
- **P2** — Slows staff, acceptable for pilot
- **P3** — Cosmetic / nice-to-have

## Status

- **OPEN** — Reported, not yet triaged
- **TRIAGE** — Understood, fix planned
- **FIXED** — Resolved and verified
- **DEFER** — Will not fix in pilot phase
- **ESCALATE** — Needs owner/manager decision
